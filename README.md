# ONCOmitra
AI-assisted oral cancer care tracking system focused on closing the gap between screening, referral, diagnosis, treatment, and follow-up. The project enables risk-based prioritization, closed-loop referrals, patient tracking, and outcome monitoring to reduce loss to follow-up and improve continuity of care.
